== 二、后端修的 9 个问题 ==

#1 **簇翻 4 倍（88 → 22）**
   每跑一次全链，cluster 阶段插 22 个新簇，旧的不删（要留历史 ✅）
   → 但读接口查了全表 → 前端显示 88 个簇、P0 显示 8 个 ✅ ✗
   修法：新增 `hub/persistence/current.py`（`current_run_id()` / `current_cluster_ids()`），
        charts/cluster-tiers、charts/clusters、report 簇导出 **三处按最新 run 过滤**
        + `/api/charts/clusters` 加 `run_id` 参数 → **可看历史某一次** ✅
   验证：P0=2 / P1=5 / P2=8 / P3=7 ✅，导出 22 行 ✅

#2 `action_outcome` 571 条 —— **查清不是 bug**
   `outcome.py:84` 本来就按 `(proposal_id, treat_spu)` 去重；571 ≈ 78 提案 × 7 商品 ✅

#3 **`/api/handle/{id}/trace` 查不到 span**（前端 token 永远 0）
   三层修复：
     a) `handle()` 里 **`set_trace_id(ctx.trace_id)`**（原来从没设过 → span 全落 `no-trace`）
     b) `save()` **沿用当前 trace_id**（原来自己又生成一个 → 和 span 的对不上 ✅）
     c) 接口三层兜底：精确 trace_id → LIKE run_id 前 8 位 → **时间窗内的 `no-trace` span**
   最终前端改读 **`agent_run.tokens_in/out`**（权威字段，一直是对的 ✅）

#4 **`ingest` 阶段硬编码 `data/mock/`**
   `_stage_ingest` 现在支持 `params["files"]`；没传则回退**并在日志里明说**
   "⚠️ 入队时没有指定 files → 回退到 data/mock 的固定清单（仅本地演示）"
   → 生产上不会以为"我上传的文件被处理了"其实读的是另一批 ✅

#5 **待批提案无待办（8 条里 7 条点批准 404）**
   查清：7 条全是测试夹具造的（`trace=exec-test-*` 5 条 + 旧 `propose-*` 2 条）
   → 标 `SKIPPED`（**不删，保留审计痕迹** ✅）
   → 给 `check_execute.py` 加收尾函数，以后不再留这种"点进去 404"的死数据

#6 `/api/brief` 加 **`inputs`**（来源指标）—— 部分完成
   字段有了，但内容是嵌套噪音（`status[0][1][0].n`）
   **没做完**：要先把 `collect_inputs()` 的展示契约定下来（哪些指标、叫什么名）
   前端那块已删，不影响任何页面 ✅

#7 **`/api/retro` 加区间**（`effect_point` / `ci_low` / `ci_high` / **`crosses_zero`**）
   从 `effect` JSONB 里拆出来；后端直接判"跨不跨 0"，前端不用重复逻辑 ✅

#8 **`gateway.invoke` 加 tool span**（`tool.{name}`）
   埋在 `invoke()` 里（**所有工具调用的唯一入口**，一处埋点全覆盖 ✅）
   已知：agent 的 3 个读工具**直接调裸函数、绕过网关** → 它们没有 span
        （功能正常，但要改就得先确认"读工具不需要依据校验" ✅ **待单独一轮**）

#9 **`vision.py` 的 base_url 混用 `/v1`**（**M2 的 50 次 Vision 全部 404**）
   `llm.base_url` 是 OpenAI 兼容层（必须带 `/v1`），
   而 Ollama 原生 `/api/chat` **不能带** `/v1` → 拼出 `/v1/api/chat` → 404 ✅ ✗
   修法：`vision.py` 去掉尾部 `/v1` + `.env` 显式配 `HUB_VISION__BASE_URL`
   验证：**真调通**（qwen2.5vl:3b，单张 8.9 秒，`defect_type=none/破损/开线/色差/污渍` 都有 ✅）

== 七、这一轮的教训（都记进台账）==

· **中文文案里的引号必须用「」** —— 我用 Python 脚本改代码时**第 6 次**因此语法错 ✅
  → 以后改代码用 `edit` 工具，不用"Python 脚本里塞中文字符串"
· **不能假设"点了 10 秒内会完成"** —— agent 取决于**队列里有没有 worker** ✅
· **测试清理不能用业务条件删** —— `where(row_kept==0)` 差点删掉 54 个真实批次 ✅
  （外键救的）
· **局部 import 在别的函数里看不到** —— `_current_trace_id` 必须模块级 ✅
