## 三、明确不做（附理由，避免反复讨论）

| 不做 | 理由 |
| --- | --- |
| 自动**发送**回复 / 自动改价上线 | 需企业资质 + 平台开放审核 + 店铺 OAuth；系统定位是"起草 + 审批" |
| 多租户 / 细粒度 RBAC | 单店铺场景；有 `role`（operator/supervisor）但没做租户隔离 |
| 销量预测 | 没有真实历史序列 |
| 知识库通用文档 RAG | Case RAG 更贴合业务（有 ground truth）；通用知识库无法评估 |
| 无限对话式多 Agent | 成本不可控、7B 撑不住、路径不收敛 → 无法评测。只做 Planner + Critic 两个角色 |
| `M10.reply` 状态机的"发送"环节 | 同第一条 |
