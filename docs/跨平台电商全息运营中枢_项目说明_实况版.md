## 0. 一页纸

| 项 | 内容 |
| --- | --- |
| **是什么** | 一个**后端系统**：把商家从淘宝/京东导出的评价（文本 + 买家秀图片）清洗、分类、聚成"问题簇"、按优先级排序、产出**带依据的处置提案**，经**网关审批**后执行，再用 **DID** 复盘效果 |
| **不是什么** | ❌ 不是"全自动 agent"（agent 只做**一次**判断 ✅）<br>❌ 不是"LangGraph 多步编排"（生产是手写状态机 ✅）<br>❌ 没有前端（0 行 ✅）<br>❌ 没有线上 Judge（明确不做 ✅） |
| **技术栈** | Python 3.13 / PostgreSQL / Redis Stream / FastAPI / SQLAlchemy 2.0 / Alembic / pydantic v2 / scikit-learn / openpyxl |
| **模型** | 本地 Ollama：文本 `qwen2.5:7b`、视觉 `qwen2.5vl:3b`；**云端只用于"聚合数字"场景** ✅ |
| **规模** | 后端 **~1.5 万行 / 91 个模块**；**43 条 API 路由**；**38 张表** |
| **测试** | `quick` 35 个 + `full` 58 个（含 quick），**全绿** ✅ |

## 3. 决策链（这是系统的核心，也是能讲的东西）

```text
22 个问题簇（P0 2 个）
   ↓ 规则：TOOL_BY_TOPIC[quality] = review.draft_reply
   ↓ 经验：experience.history_for(topic) → 历史有效/有害
   ↓       → 可能【升】风险等级（**只升不降** ✅）
   ↓ 提案：args 由代码构造 ✅（模型不填参数 —— 实测 7B 6/6 编参数 ✅）
   ↓ 网关：
      ① 参数校验（extra=forbid）
      ② 依据校验（EVIDENCE_MISSING / NOT_FOUND / MISMATCH）
      ③ 幂等（**只对写工具** ✅ 读工具 idempotent=False ✅）
      ④ 频控（burst=10）
      → L0/L1 执行；L2 PENDING_APPROVAL；L3 PENDING_HITL
   ↓ 人批（supervisor + confirm:true）
   ↓ 执行 + **回查**（verify：不信工具返回值，代码去库里查一次 ✅）
   ↓ action_outcome（等观察窗口，**最早 2026-11-13** ✅）
   ↓ M9 复盘（DID + 区间）→ 结论回写 experience ✅
   ↓ 结论回写 case_entry（案例库 —— 现在是 0 条，因为还没复盘完 ✅）
```

## 4. agent 到底是什么形态（**这条最容易讲错**）

```text
❌ 不是"自主规划 agent"（7B 实测做不到）
❌ 不是"LangGraph 多步 Workflow"（图只是**对照实现**）
✅ 是 **形态③：受限 agent**
   ↓
固定在 4 个决策点上：
   ① 查簇（参数代码给）② 查评价 ③ 查历史
   ④ 【模型只在这里出现一次】给定证据，判断支持什么处置
   ↓
**为什么这么定**：`14_Agent规划能力实测.md` 的实测
   · 收尾率 **0%**（6/6 用完 5 步都不给结论）
   · 参数幻觉 **6/6**（含把 36 位 UUID 抄错一位）
   → 所以：**步骤代码定、参数代码注入、模型只判一次** ✅
   ↓
后续加的两个独立角色：
   · **Critic**（第二个模型核对：无依据/不匹配/动作类型错）
     实测它能抓到"用改文案解物流问题" ✅
     **但只标记不拦** ✅（Critic 也会误判，不能给它否决权）
   · **reflect 环**（可选）：证据不足时补一步再判，**有界** ✅
```

**LangGraph 的真实位置**：

```text
✅ `hub/agent/graph.py` 有一份 LangGraph 实现
   → 和手写版 **22/22 行为等价** ✅（`15_LangGraph对照.md`）
   → 但**生产主路径是手写的** `hub/agent/handle.py` ✅
   → 理由：图的收益在"有环/多分支/需要 checkpointer"，我们**固定线性流程**用不上 ✅
```

## 5. 合规边界（**代码里真有闸门**，不是口号）

| 铁律 | 代码里怎么保证 |
| --- | --- |
| **① 图片永不出网** | `cloud_guard` 对 `KIND_IMAGE` **直接抛异常** ✅；视觉模型只连本地 ✅ |
| **② 评价原文默认不出网** | `HUB_CLOUD__ALLOW_TEXT=false` 默认 ✅；打开会在启动时警告 ✅ |
| **③ 只有聚合可上云** | `KIND_AGGREGATE` 放行 ✅；**每次出云写 `audit_log`** ✅（`cloud.request`） |
| 导出前的 PII 复查 | `report.export_*` 全部走 `redact_pii` ✅，首行写明"已脱敏 N 处" ✅ |

**为什么"图片永不出网"是真的**：`hub/multimodal/vision.py` **硬编码只连本地** ✅
（不是靠配置 ✅）—— 配置可以被改，硬编码不会 ✅
