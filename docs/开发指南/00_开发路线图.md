# 00 · 开发路线图（全流程总览）

| 项 | 内容 |
| --- | --- |
| 上游依据 | 《跨平台电商全息运营中枢_开发文档》v2.3（设计）+《后端开发实施手册》 |
| 本系列定位 | 从零带你开发，**按时间顺序**的 13 篇阶段文档，每篇 = 目标 + 架构思路 + 交付物 + 验收 + 常见坑 |
| 代码要求 | 不写完整代码，只给架构、目录、关键签名、数据流、决策与坑 |

---

## 一、怎么用这个系列

1. **严格按顺序**：每篇末尾的"验收"通过，才进入下一篇；不要跳着做。
2. **每篇都是"一个可运行的增量"**：做完一篇，系统就多一块能跑的部分，而不是等到最后才通。
3. **对照两份文档**：实现细节翻《实施手册》，设计依据翻《开发文档》，本系列只负责"带你走"。
