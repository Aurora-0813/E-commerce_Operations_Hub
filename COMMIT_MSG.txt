== 一、补数据上传接口（用户发现的真缺口）==

**问题**：整个系统只能命令行导入数据
    hub p0 <文件> --platform taobao --type review|product|sales
  42 条 API 路由里**没有任何上传入口** → 前端无法上传
  → 用户以为「只能用演示数据提前塞进去」

**而链路本身是通的**（我一开始误判了，这里更正）：
  read_file() → (RawBatch, records, MappingReport)
      → IngressRepo().save(...) → repo_ingress 里**本来就有** sales → sales_daily 的转换
  → 实测 sales_daily 有 4500 行（2026-07-25 ~ 2026-10-22）
  **所以缺的只是「一个能上传的门」**

**四个设计选择**（都写在代码注释里）：
  ① 同步不做队列：4000 行 xlsx 约 3~8 秒；走队列反而多一轮轮询
  ② 20MB 上限 + **流式写临时文件**（不一次读进内存，否则 1GB 文件把进程吃爆）
  ③ 幂等靠 IngressRepo.save 的 SHA256 → 同一个文件再传是 existed=true，**不是报错**
  ④ platform / data_type **白名单**（拼错一个字母就会写出 434 条脏记录 → 400 挡住）
  + 每次上传写 audit_log（action=data.ingest）
  + 临时文件必须删（里面有评价原文 / PII）

**实测**：
  无 token → 401 ｜ 坏 platform / 坏 data_type / 非 xlsx → 400
  空文件 → 400 ｜ 超 20MB → 413
  真文件 jd_sales_202610.xlsx (platform=jd) → **201，rows_ok=2250 / rows_bad=0**
  再传一次 → **existed=true + 同一个 batch_id**（幂等生效）

== 二、OpenAPI 元数据（`/api/docs` 从「能调」变成「能读」）==

**问题**：Swagger 里全是英文标题（FastAPI 从函数名自动生成）
    GET /api/today → "Get Today"
    GET /api/notify → "List Notify"
  分组是 default/read/write/charts，**没有一句「这组是干什么的」**
  返回结构**看不到** → 前端不知道会拿到什么

**做法**：一个后处理器（`hub/api/openapi_meta.py`），不动 43 个装饰器
  · TAGS_META：7 组中文分组 + 每组一句说明
  · META：43 个接口 × {summary, tag, description, example}
  · apply_openapi()：把这些贴进 OpenAPI JSON
  · main.py 里挂 `app.openapi = lambda: apply_openapi(_base_openapi())`

**效果**：**43/43 接口都有中文标题 + 分组 + 响应示例** ✅

**代价（说清）**：这是 **example（示例）**，不是 **response_model（模型）**
  → Swagger 能看到「长什么样」，但**不会校验真实返回**
  → 真正的 response_model 要写在装饰器上（43 个 pydantic 响应类，约 2~3 小时）
  → 现在实际靠 42 个接口的测试断言兜着

== 四、这轮踩到的两个真问题（比接口本身更值得记）==

**① 我的测试清理差点删掉 54 个真实批次**
   我写 `where(row_kept == 0)` → 匹配 54 条，里面有真实批次
   （DQE 全 drop 所以 row_kept=0，但它们是**真的数据**）
   **外键 analysis_run.batch_id 挡住了删除** —— 一句 IntegrityError 救的
   → 改成：「只按测试自己记下的 id 精确删」
   → 规矩：**测试清理不能用业务条件删**，那等于赌「条件不匹配真实数据」

**② 平台传错时 warnings 是空的（用户看不出为什么）**
   rows_ok: 0 / rows_bad: 2250，但 warnings: []
   → 现在第一条就是人话：
     「一行都没成功（2250 行全坏）。最常见的原因是 platform 传错 ——
       这个文件可能不是 taobao 的导出。下一步：确认文件名里的平台，再重传」

== 五、编码教训（第 4 次犯同一个错）==
